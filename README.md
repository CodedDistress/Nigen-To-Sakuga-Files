# Nigen To Sakuga — Files

Download host for [Nigen To Sakuga](https://github.com/CodedDistress/Nigen-To-Sakuga).

This repository holds no source code. It exists so the app's installer can
download optional components anonymously.

## Releases

- **models-v1** — 39 optional RIFE interpolation models. The installer bundles
  8 curated models and works fully without these; its "Optional RIFE models"
  page downloads from here when you tick one.

Models are RIFE by [hzwer](https://github.com/hzwer/Practical-RIFE), converted
to ncnn format by [TNTwise](https://github.com/TNTwise/Rife-Vulkan-Models),
MIT licensed.

No anime or other footage is distributed here.
